## Practical rules

1. Put the header at the top of each project-owned source file, after a required
   interpreter line such as `#!/usr/bin/env python3`.
2. Do not add this header to generated files, vendored dependencies, lockfiles,
   or files owned by another project.
3. Keep third-party copyright and license notices unchanged.
4. When modifying an existing file, add a clear notice that the file was changed
   if redistribution requires it under Apache 2.0 section 4(b).
5. Keep the repository-level [LICENSE](../LICENSE) and [NOTICE](../NOTICE) files
   in the project root.
